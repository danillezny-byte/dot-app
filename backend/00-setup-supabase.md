# Этап 1.1 — Настройка Supabase (15 минут)

> Ничего не платим. Карта не нужна. Это полностью бесплатно для нашего объёма.

---

## Что мы сделаем

Зарегистрируем Supabase-проект в EU регионе. После этого у нас будет:
- База данных PostgreSQL
- Сервис авторизации (email + пароль, Apple, Google)
- Хранилище файлов (для картинок и PDF в заметках)
- API ключи, которые мы потом подключим к коду

---

## Шаг 1. Регистрация (3 минуты)

1. Откройте **https://supabase.com**
2. Нажмите **Start your project** в правом верхнем углу
3. Выберите **Continue with GitHub** (если есть аккаунт) или **Continue with email**
   - GitHub удобнее: больше ничего не нужно подтверждать
   - Email: придёт письмо со ссылкой подтверждения

---

## Шаг 2. Создание проекта (5 минут)

После входа вы попадёте в Dashboard. Там будет кнопка **New Project**.

Заполните форму:

| Поле | Что вписать |
|---|---|
| **Organization** | Оставьте «Personal» (создастся автоматически) |
| **Name** | `dot` |
| **Database Password** | Нажмите кнопку **Generate** справа от поля. Сохраните пароль в надёжное место (1Password, Notes, что угодно) — он понадобится только при ручном доступе к БД, не для повседневной работы |
| **Region** | ⚠️ Важно: **Frankfurt (eu-central-1)** — это EU, как мы решили |
| **Pricing Plan** | **Free** (он выбран по умолчанию) |

Нажмите **Create new project**.

⏳ Supabase будет создавать инфраструктуру **2-3 минуты**. Это нормально. Не закрывайте вкладку.

---

## Шаг 3. Получение ключей (1 минута)

Когда проект создастся, вы увидите главную панель проекта.

В левом меню найдите иконку **шестерёнки** (Project Settings) → внутри секцию **API**.

Там будет три важных значения, скопируйте их в безопасное место:

```
Project URL:        https://xxxxxxxxxx.supabase.co
anon public key:    eyJhbGc... (длинная строка)
service_role key:   eyJhbGc... (другая длинная строка) — СЕКРЕТ, никогда не публикуй
```

**Что есть что:**
- **Project URL** — адрес вашего бэкенда. Им можно делиться (он публичный по природе).
- **anon public key** — ключ, который пойдёт в фронтенд-код. Им можно делиться, но он сам по себе ничего не разрешает: всю безопасность даёт Row Level Security (мы её настроим в шаге 1.2).
- **service_role key** — **СЕКРЕТНЫЙ ключ**, обходит все правила безопасности. Его НЕЛЬЗЯ публиковать в коде фронтенда. Используется только в серверной логике (Edge Functions). Пока он нам не нужен, но **никому не показывайте**.

---

## Шаг 4. Включение нужных провайдеров авторизации (5 минут)

В левом меню → **Authentication** → **Providers**.

### Email

Уже включён по умолчанию. Найдите **Email** в списке → убедитесь, что галочка **Enable Email provider** включена.

⚠️ В блоке **Confirm email** можно временно **отключить** подтверждение email на время разработки — иначе при каждой регистрации придётся ловить письмо. Включим обратно перед запуском.

### Apple ID
Найдите **Apple** в списке. Пока **просто прочитайте**, что там написано, и оставьте выключенным. Apple Sign In требует Apple Developer аккаунт ($99/год), который нам пока не нужен. Включим, когда будем выкладываться в App Store.

### Google
Найдите **Google** в списке. Тоже пока **оставьте выключенным**. Подключение Google требует создания проекта в Google Cloud Console и настройки OAuth — это отдельный 30-минутный квест. Сделаем позже, когда сам Email-flow заработает.

---

## Шаг 5. Сохраните ключи в проект

Создайте в корне проекта файл `.env.local` (если его нет) и вставьте:

```
VITE_SUPABASE_URL=ваш_Project_URL_сюда
VITE_SUPABASE_ANON_KEY=ваш_anon_public_key_сюда
```

⚠️ Файл `.env.local` **не должен попасть в Git**. В нашем проекте этот файл уже в `.gitignore` (или будет добавлен).

Когда сделаете все 5 шагов — напишите мне «готово, ключи прислал» и **в чат вставьте только Project URL и anon public key** (service_role НЕ присылайте — он секретный, и я его всё равно не буду использовать).

## Если что-то не работает

| Проблема | Решение |
|---|---|
| Не приходит письмо подтверждения email | Проверьте папку «Спам». Иногда письма от Supabase идут туда. |
| Проект «висит» в статусе Initializing более 10 минут | Откройте чат с поддержкой Supabase прямо в дашборде, или просто удалите проект и создайте заново. |
| Не уверен, какой регион выбрать | **Frankfurt (eu-central-1)**. Если его нет в списке — **West EU (Ireland)**. |
| Хочу удалить проект и начать заново | Settings → General → внизу страницы кнопка **Delete project**. Безопасно для тестового аккаунта. |
